# shadow-vault (`svault`)

> Криптографическое хранилище с нулевым доверием, стеганографией и двухфакторной аппаратной привязкой — скрывайте конфиденциальные файлы внутри обычных изображений PNG и аудио, защищайте с помощью Argon2id + ChaCha20-Poly1305 + Windows DPAPI или создавайте ложные контейнеры правдоподобного отрицания с двойным паролем.

### Обзор проекта

`shadow-vault` (`svault.exe`) — автономный криптографический инструмент и стеганографический комплекс на языке Rust без внешних зависимостей, обеспечивающий защиту критически важных данных:

1. **Двухуровневое аутентифицированное шифрование (`SVLT` v1/v2)** — алгоритм деривации ключа **Argon2id** + **ChaCha20-Poly1305** AEAD с аппаратной привязкой **Windows DPAPI (`CryptProtectData`)**.
2. **Правдоподобное отрицание и контейнеры-приманки (`src/decoy.rs`)** — хранение основного секрета и ложных данных в одном файле; при принуждении пароль приманки открывает только безобидные данные.
3. **Беспотерьная медиа-стеганография**:
   - **PNG**: внедрение приватного вспомогательного блока `svLt` перед `IEND` с контролем CRC-32.
   - **WAV**: суб-блоки RIFF и модификация LSB в 16-битных аудиосэмплах PCM.
   - **BMP**: LSB-модуляция в 24-битных RGB-каналах с сохранением 4-байтового выравнивания строк.
   - **MP3**: скрытие во фреймах ID3v2 `PRIV` или межфреймовом заполнении MPEG Layer III.
4. **Универсальная оценка вместимости (`capacity`)** — расчет доступной полезной емкости в `.bmp`, `.wav`, `.png`, `.mp3`.
5. **Разделение секрета Шамира (`M-из-N`, `src/shamir.rs`)** — арифметика с константным временем в $\text{GF}(256)$ для разделения ключей на $N$ частей с порогом сборки $M$.
6. **Аудит надежности паролей и энтропии (`src/audit.rs`)** — расчет энтропии Шеннона и обнаружение уязвимых шаблонов.
7. **Хранилище TOTP 2FA RFC 6238 (`src/totp.rs`)** — автономный генератор кодов двухфакторной аутентификации с защитой от тайминг-атак.
8. **Безопасный буфер обмена с автоочисткой (`src/clipboard_guard.rs`)** — предотвращение записи в журнал Windows 10/11 и удаление данных по таймеру TTL.
9. **Коррекция ошибок Коши Рида-Соломона (`src/armor.rs`)** — восстановление полного контейнера из любых $K$ неповрежденных блоков из общего числа $K+M$.
10. **Архивирование каталогов с манифестом (`src/archive.rs`)** — защита от атак Zip Slip / Zip Bomb и пофайловая проверка SHA-256.
11. **Аутентификация 2FA с ключевым файлом (`src/keyfile.rs`)** — потоковое хэширование HMAC-SHA256 для физических USB-ключей.
12. **Потоковое блочное шифрование (`src/stream.rs`)** — обработка блоков по 4 МиБ с расходом памяти $O(1)$ для файлов любого размера.
13. **Отчет о визуальных и статистических искажениях (`src/diff.rs`)** — расчет показателей MSE, PSNR, SNR и сдвига энтропии.
14. **Таймер мертвеца и автоуничтожение (`src/guard.rs`)** — гарантированное 3-проходное криптографическое затирание файла при $K$ неверных попытках ввода пароля.
15. **Генератор паролей BIP-39 и CSPRNG (`src/passgen/`)** — создание мнемонических фраз из словаря на 2 048 слов и случайных токенов.
16. **Единый структурированный JSON-вывод (`--json`)** — интеграция со скриптами автоматизации и CI/CD.
17. **Ротация ключей (`rotate`)** — безопасная смена паролей и привязки DPAPI без записи открытого текста на диск.
18. **Контрольный манифест целостности (`canary`)** — обнаружение несанкционированных изменений файлов в каталогах.
19. **Аппаратные токены FIDO2 и Windows Hello (`src/hardware_token/`)** — поддержка ключей YubiKey и биометрии TPM через протокол CTAP2 PRF.
20. **Постквантовое гибридное инкапсулирование (`src/pq_kem/`)** — сочетание алгоритма X25519 и стандарта NIST FIPS 203 ML-KEM-768.
21. **Принудительное обнуление памяти (`zeroize`)** — затирание криптографических ключей в оперативной памяти после использования.

### Быстрый старт

```bash
# 1. Зашифровать файл паролем с аппаратной привязкой DPAPI
svault encrypt -i wallet-seed.txt -o wallet.svault -p "надежный-пароль" --dpapi

# 2. Создать контейнер с правдоподобным отрицанием (основной секрет + приманка)
svault encrypt -i classified.txt --decoy shopping-list.txt -o deniable.svault \
  -p "основной-пароль" --decoy-passphrase "пароль-приманки" --padding 512

# 3. Расшифровать контейнер паролем приманки (открывается только ложный список)
svault decrypt -i deniable.svault -o revealed.txt -p "пароль-приманки"

# 4. Проверить метаданные контейнера без расшифровки
svault inspect deniable.svault

# 5. Скрыть контейнер внутри изображения PNG
svault embed -c wallpaper.png -s classified.txt --decoy shopping-list.txt -o wallpaper-stego.png \
  -p "основной-пароль" --decoy-passphrase "пароль-приманки"

# 6. Извлечь подлинный секрет из изображения PNG
svault extract -c wallpaper-stego.png -o restored-seed.txt -p "основной-пароль"
```
